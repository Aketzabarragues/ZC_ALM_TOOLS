# Librerías de Terceros (Vendor)

Coloca en esta carpeta el instalador del wrapper de Siemens:
`siemens_tia_scripting-x.x.x-cp312-cp312-win_amd64.whl`

Se puede obtener a través del Siemens Industry Online Support (SIOS) o la intranet corporativa.

**Instalación:**
```bash
pip install lib/siemens_tia_scripting...whl
```
