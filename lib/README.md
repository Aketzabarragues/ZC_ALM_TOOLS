# Librerías de Terceros (Vendor)

Esta carpeta contiene el wrapper nativo de Siemens TIA Portal Openness.
Dado que es código compilado (C++), debes instalar la versión exacta que coincida con tu versión de Python (3.12, 3.13 o 3.14).

**Instalación:**
Abre la terminal en la raíz del proyecto y ejecuta el comando correspondiente a tu Python:

Para Python 3.12:
`pip install lib/siemens_tia_scripting-x.x.x-cp312-cp312-win_amd64.whl`

Para Python 3.13:
`pip install lib/siemens_tia_scripting-x.x.x-cp313-cp313-win_amd64.whl`
